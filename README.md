# Lista 5 - Machine Learning

Este repositorio contiene la solución a la quinta lista de ejercicios. 

## Estructura
- `data/`: Contiene los archivos CSV usados en los experimentos.
- `src/lista5/`: Módulo local con el código reutilizable para la carga de datos, modelos y cálculo de riesgos.
- `notebooks/`: Cuadernos con la ejecución de los experimentos y sus respuestas.

## Instalación y Ejecución
1. Crear y activar un entorno virtual para evitar instalaciones dobles en el sistema, para windows:  `python -m venv .venv` y despues `.venv\Scripts\activate`   
2. Instala las dependencias: `python -m pip install -r requirements.txt`
3. Instala el paquete local en modo editable: `pip install -e .`
4. Ejecuta VS para correr los cuadernos ubicados en la carpeta `notebooks/`.
